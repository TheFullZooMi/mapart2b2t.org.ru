Добавить мап-арты

Помощник для владельца сайта: добавление и удаление артов. Перетащите PNG, заполните данные, скачайте готовые файлы и загрузите их в репозиторий. ← к галерее

1. База данных

data.json не загружен

Страница пытается прочитать data.json рядом с собой. Если открыта не с сайта (а как файл с компьютера), выберите его вручную: от него зависят следующие номера и подсказки ников.

2. Значения для новых файлов

Эти значения подставляются в каждый новый файл, потом их можно поменять в карточке. Если дата не нужна, отметьте «Без даты» (или оставьте поле пустым): в базу запишется 0000-00. «Пикселей на карту» нужно для определения размера: в обычном PNG карта 128×128, то есть арт 4×3 имеет размер 512×384.

3. Изображения

Перетащите PNG сюда или нажмите, чтобы выбрать
Можно сразу несколько файлов

4. Удалить арты из data.json

Отметьте арты, которые нужно убрать. Сразу ничего не удаляется: отметки учитываются в шаге «Результат», в скачанном data.json этих записей уже не будет. Картинки из папки maps в репозитории вы удаляете сами, список имён появится в результате. Номера новых артов не занимают места удалённых.
