Добавить мап-арты

Помощник для владельца сайта. Перетащите PNG, заполните данные, скачайте готовые файлы и загрузите их в репозиторий. ← к галерее

1. База данных

data.json не загружен

Страница пытается прочитать data.json рядом с собой. Если открыта не с сайта (а как файл с компьютера), выберите его вручную: от него зависят следующие номера и подсказки ников.

2. Значения для новых файлов

Эти значения подставляются в каждый новый файл, потом их можно поменять в карточке. «Пикселей на карту» нужно для определения размера: в обычном PNG карта 128×128, то есть арт 4×3 имеет размер 512×384.
